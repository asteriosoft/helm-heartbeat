# heartbeat

A Helm chart for an independent heartbeat watcher that polls service health endpoints and notifies via Telegram

![Version: 0.1.0](https://img.shields.io/badge/Version-0.1.0-informational?style=flat-square) ![Type: application](https://img.shields.io/badge/Type-application-informational?style=flat-square) ![AppVersion: 1.0.0](https://img.shields.io/badge/AppVersion-1.0.0-informational?style=flat-square)

## Installing the Chart

To install the chart with the release name `my-release`:

```console
$ helm repo add helm-heartbeat git+https://bitbucket.org/asteriosoft/helm-heartbeat?ref=0.1.0
$ helm install my-release helm-heartbeat/heartbeat
```

The watcher polls the health endpoint of each configured target and sends a
Telegram notification once a target has been unavailable for longer than the
failure threshold, and a recovery notification once it is healthy again. It runs
independently of Prometheus/Alertmanager on purpose, so it can still alert when
those components themselves are down.

## Values

| Key | Type | Default | Description |
|-----|------|---------|-------------|
| failureThreshold | int | `300` | Seconds a target must stay down before an alert is sent (300 = 5 min) |
| hostname | string | `""` | Optional label included in notifications (e.g. the environment name) |
| image | string | `"python"` | Docker image source (Python is enough; the watcher only uses the stdlib) |
| imagePullPolicy | string | `"IfNotPresent"` | Image pull policy |
| imagePullSecrets | string | `nil` | Image pull existing secret |
| imageTag | string | `"3-alpine"` | Docker image tag |
| interval | int | `30` | Seconds between poll cycles |
| logChecks | bool | `true` | Log the result of every check each cycle, not just state changes |
| nodeSelector | object | `{}` | Pod's [node selector](https://kubernetes.io/docs/concepts/configuration/assign-pod-node/) |
| pingUrl | string | `""` | Optional external dead-man's-switch URL (e.g. healthchecks.io) pinged every cycle so total watcher/cluster death is detected off-cluster |
| resources | object | `{"limits":{"memory":"64Mi"},"requests":{"cpu":"10m","memory":"32Mi"}}` | Pod resources definition |
| targets | list | `[]` | List of health-check targets, each an object with `name` and `url`. Every target is polled independently each cycle. |
| telegram.botToken | string | `""` | Telegram bot token used to send notifications |
| telegram.chatId | string | `""` | Telegram chat id notifications are sent to |
| timeout | int | `5` | Per-request timeout in seconds; a slower response counts as unhealthy |
